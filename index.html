💾 Computer Memory Hierarchy

Trade-offs between access speed, storage capacity, and monetary cost
Registers (~0.5 - 1 ns | < 1 KB)
Cache L1, L2, L3 (~1 - 10 ns | 32 KB - 64 MB)
Main Memory / RAM (~50 - 100 ns | 8 GB - 128 GB) ⬅ [Subject of this Simulator]
Solid State Storage / NVMe SSD (~10 - 100 µs | 512 GB - 4 TB) [Swap Space / Backing Store]
Secondary Hard Disk & Cloud Storage (~5 - 15 ms | Multi-Terabytes)
⬆ Higher Speed & Cost per Bit ⬇ Greater Storage Capacity
